# English Placement App

Интерактивный сайт для определения уровня английского языка потенциального ученика: грамматика, лексика, чтение и аудирование без письма.

## Запуск

```bash
node server.js
```

Откройте:

```text
http://localhost:3000
```

## Почта

1. Скопируйте `.env.example` в `.env`.
2. Укажите `RESULT_RECIPIENT_EMAIL`.
3. Настройте SMTP-поля вашего почтового провайдера.

Если SMTP не настроен, результаты не потеряются: сервер сохранит JSON-файлы в `data/results/`.

## Что внутри

- 36 вопросов уровня A1-C2.
- Секции: grammar, vocabulary, reading, listening.
- Таймер 35 минут.
- Автоматический расчет CEFR-уровня.
- Серверная проверка ответов.
- Email-отчет для преподавателя.
